AizenRex Search-man

v0.3.7 Professional Edition (.NET 9 + WebView2)
Creator, Lead Software Architect & Developer
Riyad Aizen

AizenRex Search-man is a hyper-optimized desktop search and indexing engine engineered for instant microsecond retrieval across 2,500,000+ files and local and connected storage libraries.

Architecture & Engineering:

  • Directory String Interning: Custom high-concurrency string pool reduces memory consumption by 85%+ (<350 MB RAM for 2.5M files).
  • Compact V2 Binary Cache: Disk footprint reduced by 68% (155 MB) with microsecond startup deserialization.
  • Direct NTFS USN Engine: Bare-metal MFT parsing in C# .NET 9 with zero Win32 shell overhead.
  • Connected Storage Support: Efficient indexing and search across local and mounted file systems.
  • VSync Virtual Grid: Silky-smooth 60–144 FPS list rendering with zero GC stutter or frame drops.

Search Syntax & Power Operators

AizenRex Search-man Ultra-Fast Query Guide
superman 2006
Smart Sub-sequence Gap Match: Matches Superman Returns (2006) even with tokens separated by words.
ext:mp4 | ext:mkv|mp4
Extension Filter: Matches only specific file formats or multiple extensions with pipe (|).
type:video / audio / doc
Category Filter: Filters by category (video, audio, image, doc, exe, archive, folder, file).
path:Documents
Directory Path Filter: Forces matching within parent directory path.
!node_modules !temp
Exclusion Operator (!): Exclude items containing specific words or directory names.
"avengers endgame"
Exact Phrase Match (""): Matches the exact contiguous phrase inside quotes.
setup*.exe / img_??.png
Wildcards (* and ?): Asterisk matches multiple characters, question mark matches one.
