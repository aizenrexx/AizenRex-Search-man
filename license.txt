1. INTRODUCTION & PURPOSE
--------------------------------------------------------------------------------
AizenRex Search-man is an ultra-fast, lightweight desktop search and indexing suite
engineered for instant microsecond retrieval across millions of local files and
local and connected storage libraries.

2. ARCHITECTURAL TRANSPARENCY & DATA PRIVACY
--------------------------------------------------------------------------------
- ZERO TELEMETRY / ZERO SURVEILLANCE:
  AizenRex Search-man operates completely offline and private on your machine. None of
  your file names, file paths, contents, queries, or indexing data are ever
  transmitted to any external server or third party.
- LOCAL HIGH-SPEED INDEXING:
  Direct Master File Table (MFT) scanning and directory indexing operate purely
  in local system RAM and serialize to your local user application profile
  (%LocalAppData%\AizenSearch\).
- CONNECTED STORAGE LIBRARIES:
  Connected libraries can be indexed through supported local or mounted paths.
  Indexing remains local and no files are uploaded.
- ENGINEERING DISCLOSURE:
  Conceived, designed, and architected by Riyad. Advanced AI-assisted algorithmic
  optimization was leveraged during concurrency profiling, high-speed IPC bridge
  design, and high-performance data serialization.

3. IN-PLACE UPGRADE & DOWNGRADE GUARANTEE
--------------------------------------------------------------------------------
- Safe Upgrade/Downgrade: You may install newer or older versions of AizenRex Search-man
  at any time. The installer guarantees that all your existing indexes, user
  preferences, and cached databases located in %LocalAppData%\AizenSearch remain
  100% intact with zero data loss.
